# Project Definition — Marketing Websites Freelancer Roadmap (`roadmap`)

## Overview
An ultra-crafted, interactive single-page web application representing the **Marketing Websites Freelancer Roadmap**, **Marketing & Sales Parallel Track**, and **AHKH Studio Services & Scope Playbook**.

## Core Goals & Scope
1. **21st.dev / Social-Media Grade Visual Experience**:
   - OLED dark cosmos aesthetic, spotlight mouse-tracking cards, glowing progress timeline beams, bento-grid strategy cards, glassmorphic drawers, and micro-interactions.
2. **Literal Course & Book Breakdown**:
   - Every course, book, and guide mentioned in the roadmap is broken down into its actual modules, chapters, and individual lessons so the user can track granular lesson-by-lesson completion.
3. **Code-Editable Data Architecture**:
   - All roadmap content (phases, courses, modules, lessons, tracks, milestones, and studio rules) lives in `data/roadmap-data.js` so future roadmap edits require only simple code changes in one place.
4. **Local Browser Persistence (`localStorage`)**:
   - Tracks completion of milestones, phases, courses, modules, individual lessons, projects, and checklists locally in the browser (`localStorage`), with JSON export/import backup and personal notes.
